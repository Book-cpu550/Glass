# Glass v4.2.3 — Interactive science notebooks

Glass is **100% AI-coded**: all Glass-specific application code was generated by AI under human direction. Third-party components retain their own authorship and licenses.

## What’s new

- **Easier writing and navigation:** cursor `/` insertion, Ctrl K command search, heading outline and section folding, focus mode, and formatting beside selected text. Times New Roman remains the default.
- **Interactive math:** 2D/3D vector fields, equation sliders, graphs linked to note equations, and numerical coordinates, slopes, roots, intersections, and signed-area inspection. Inline graph viewers rotate/pan/zoom; Save view updates the still image used by notes and PDF export while preserving ink.
- **Physics:** a separate graphing tab, 64 symbols and 48 references, 2D/3D projectile and falling-object simulations with/without quadratic air resistance, wind/crosswind, numerical flight/height/range/speed/energy results, and playback with scrubbing and normalized velocity/net-force arrows.
- **Chemistry and biology:** qualified local VSEPR shape estimates and appearance explanations; inline 3D molecule exploration with atom/bond/distance/angle inspection; clickable biology explanations, editable annotations, and hide-labels quizzes.
- **Study and collaboration:** local flashcards from selected text, equations, or diagrams with Again/Good/Easy scheduling; participant chips, shared cursors/selections, offline state, pending-delivery feedback, and relay-confirmed synchronization.
- **Reliability fixes:** graph Undo/Redo preserves other mode drafts; irrelevant physics inputs no longer block simulations; mouse-selected 3D cameras survive edits; Reset view handles 3D correctly; DOI/URL metadata refresh updates an existing citation instead of creating a duplicate. Added rendering/removal guards and clearer graph controls and presets.

Existing notebook/folder/tag organization, editable prose and math, tables/drawings, searchable science references and symbols, periodic table/study charts, offline writing review, optional Codex AI/photo transcription, MLA citations, PDF/Markdown import, PDF export, backups/history/recovery, encrypted sharing, and optional accounts remain included.

## Downloads

Install **Glass-Setup-4.2.3.exe**, or extract the complete **Glass-v4.2.3-win32-x64.zip** and run Glass.exe. Verify downloads against **SHA256SUMS.txt**.

**The Windows installer is unsigned.** No publisher signing certificate is available. Notes and local account/session data remain separate from application files.

## Privacy and practical limits

New editing, graphing, and study interactions run locally. Explicit collaboration uses the configured encrypted sharing relay; free hosting quotas apply. Flashcards and review progress remain local. AI requires the recipient’s own installed/signed-in Codex and internet access; developer accounts, credentials, notes, and deployment secrets are not distributed. Optional PubChem, citation metadata lookup, updates, and AI requests contact their services when requested.

Graphs and simulation results are numerical approximations; molecular geometry is generated, not experimental. Linked equations must use supported graph notation. Active linked graphs follow source edits; Save view updates the static image. Offline core work and readable PDF still images remain available. “Synced to sharing service” confirms relay receipt, not that every collaborator is online.
