# Glass v4.2.2

Glass is **100% AI-coded**: all Glass-specific application code was generated by AI under human direction. Third-party components retain their own authorship and licenses.

## Highlights

- **Writing:** continuous Times New Roman document editing with mixed prose/equations, custom matrices, editable bounds, tables, drawings, scientific captions/cross-references, and page breaks.
- **Science tools:** Cartesian/polar/3D graphs, chemical structures and generated 3D conformers, editable biology diagrams and sequence tools, and shared figure layout/undo controls.
- **References and symbols:** searchable math, chemistry, and biology libraries; a complete 118-element periodic table and six chemistry charts; subject symbol palettes, a Greek-letter picker, reference navigation arrows, and corrected formula previews.
- **Review and research:** offline English spelling/grammar bubbles with Accept/Dismiss and a personal dictionary; reviewed AI edits with context controls; photo transcription; MLA citations, public URL/DOI metadata lookup, locally saved citation drafts, and Works Cited pages.
- **Organization and recovery:** notebooks, nested folders, right-click tags/movement, drag-and-drop ordering, pins/backlinks, indexed search, substantial-edit history, and portable checksummed backups with safety copies on restore.
- **Import and export:** reviewed PDF/Markdown/LaTeX/text import, optional PDF page images, read view, and PDF preview/export with paper, margin, orientation, and page-number controls.
- **Sharing and accounts:** encrypted edit/view invitations, concurrent document/title editing, offline edits and reconnect/merge, persistent internet sharing while the owner is offline, and optional username/password accounts with encrypted cross-device shared-document shortcuts. Includes sign-out, global session revocation, and password-confirmed account deletion.
- **Desktop polish:** softer colors/text, bounded page/dialog scrolling, removal of note-layout/template dropdowns, and verified local updates.

## Downloads

Use **Glass-Setup-4.2.2.exe** to install, or extract **Glass-v4.2.2-win32-x64.zip** completely and run Glass.exe. Compare the downloaded files with **SHA256SUMS.txt**.

**The Windows installer is unsigned.** No publisher code-signing certificate is available. Existing notes remain separate from the application files.

## Privacy and limits

Core editing, bundled references, scientific tools, offline writing review, and PDF import/export work locally. Only documents explicitly shared/joined are uploaded for collaboration. Cloud storage contains encrypted document updates and encrypted account shortcuts; optional accounts retain a username, salted verifier, and necessary security records, without email or profile forms. Local notes remain accessible after sign-out. The Cloudflare sharing service has free-tier quotas and app capacity limits; persistent storage is not an unlimited-storage or uptime guarantee. Keep local backups. See [cloud sharing and security boundaries](CLOUD_SHARING.md).

AI requires the recipient's own installed/signed-in Codex and internet access. PubChem, URL/DOI lookup, update checks, and AI imports contact their respective services only when requested. No personal notes, account sessions, deployment secrets, API keys, or developer Codex credentials are distributed.

## Validation

68 unit tests passed. Application checks cover editor/math/figure workflows, all symbol previews, navigation, writing review, citations, backup/recovery, PDF import/export, concurrent sharing, and account UI. A live Cloudflare test saved an encrypted document, disconnected its owner, redeployed the worker, and recovered both document content and the encrypted account shortcut from a fresh session. Authorization tests reject unauthenticated and cross-account vault access, browser-origin requests, forged room-creation sessions, incorrect deletion passwords, and revoked sessions.

PDF extraction order, scientific diagrams, chemical conformers, AI suggestions, and fetched citation metadata should be reviewed. Scanned PDFs can be preserved as images; automatic offline OCR is not included. Security checks are not an independent security audit or a guarantee against every exploit.
